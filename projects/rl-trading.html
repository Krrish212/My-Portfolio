Skill-Conditioned RL for Economically Meaningful Trading

One PPO agent that learns three distinct trading behaviours — and the finding that behavioural diversity and economic value pull against each other unless you force them together.

Markets change. A single policy has to average across conditions it should be treating differently.

Volatility regimes alternate, correlations restructure, and a strategy that prints money in one period fails in the next. Standard reinforcement learning for trading learns one policy mapping market state to action, so policy improvement is driven by an advantage signal averaged over structurally different conditions. The result is a decision function that is adequate everywhere and optimal nowhere.

This project conditions a single PPO agent on a latent skill index, sampled at the start of each episode and held fixed, so one network can carry several behavioural modes. A discriminator is trained to identify the active skill from the states the agent visits, paying the policy an intrinsic reward for being distinguishable. That diversity signal is constrained by an excess-return reward — portfolio return minus market return, per step — so that riding a rising market scores approximately zero and only genuine alpha counts.

The headline result is a negative one that turned out to be more interesting than the positive one. Diversity and profitability actively compete, and the fix was not a hyperparameter. Every attempt to tune the tension away on a single asset failed. Broadening the training distribution across four equities resolved it in one move.

02How it works
rtotal = rexcess + λ · rdiv
  • Skill conditioning A one-hot skill index is appended to the seven-feature market observation, sampled per episode and held fixed. One network, three behavioural modes, no architectural change to PPO.
  • Diversity reward The discriminator's log-confidence that it can identify the active skill from the resulting state — normalised to [0, 1] so it cannot swamp the profit term, which it does at raw scale.
  • Excess return Portfolio change minus market change, per step. Buy-and-hold scores roughly zero, so the agent cannot be paid for market drift it did nothing to earn.

04What the table shows

0.99 discriminator accuracy. One trade per episode. The agent had learned that the cheapest way to be identifiable is to do nothing.

Read the accuracy column against the eval column and they do not track each other. Row 03 has the highest accuracy on the page and one of the worst returns — three skills, each pinned to a permanent position, generating tightly clustered trajectories that are trivial to classify at zero trading cost. Row 08 scores 0.81 and still performs worse than row 06 at 0.95. Separability in state space is not economic validity, which means discriminator accuracy cannot be used alone as a measure of skill quality. Skills need to be judged jointly on discriminability, trading behaviour, and out-of-sample return.

Rows 06 to 08 are the real result. Once the reward is honest, every single-asset intervention fails — λ magnitude, annealing schedule, warmup length, twice the training steps, thirty years of history. Row 09 changes only the training distribution and the collapse resolves at around 250k steps. The binding constraint was distributional, not parametric: one asset under an excess-return objective supports roughly one reliably profitable strategy, and three skills cannot be carved out of one.
